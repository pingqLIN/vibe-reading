網頁翻譯相關設定（變更即時生效，無需重新整理）

在網頁上按住此鍵並將滑鼠移到段落上，即翻譯游標所指的那一段。
常駐右下角的翻譯球。關閉後仍可用工具列圖示／Alt+T／右鍵選單翻譯。

專業辭庫（選用）

相容於 Immersive Translate terms 的 source,target,tgt_lng CSV 格式。可從本機載入、直接貼上，或從 GitHub 辭庫目錄挑選多個檔案。
此功能預設關閉。Vibe Reading 只負責讀取與套用你指定的辭庫資料，不內建、轉授權或保證任何第三方辭庫。 若使用第三方來源（包含 Immersive Translate terms 相容資料），請自行確認來源、授權、內容正確性與持續可用性。
適合固定版本或自行維護的辭庫。選取後會把內容儲存在本機 Chrome storage。
第一列至少需包含 source,target；建議包含 tgt_lng。空白或 auto 表示所有目標語言。
推薦直接貼 GitHub 的辭庫目錄網址，Vibe Reading 會讀取目錄並讓你勾選要使用的 CSV。也保留直接 CSV URL 作為進階模式。
例如 https://github.com/immersive-translate/terms/tree/main/glossaries。 目前支援公開 GitHub repository 的 /tree/<branch>/<folder> 目錄。
尚未選擇辭庫
貼入可直接回傳 CSV 文字內容的網址，例如 GitHub Raw URL。遠端來源僅允許 HTTPS；本機開發可用 localhost / 127.0.0.1。
變更 GitHub 目錄、勾選項目或直接 CSV URL 後，此確認會自動失效，需重新勾選。
啟用後只更新你已選取的辭庫，最多每 24 小時抓取一次；目錄中新出現的檔案不會被自動加入。抓取失敗會沿用上次成功快取。
Immersive Translate terms 相容方式
可直接填入 https://github.com/immersive-translate/terms/tree/main/glossaries，讀取清單後自行選擇要使用的辭庫。 Vibe Reading 只採用資料格式與目錄讀取相容設計，不會預設連線、預載、選取或重新散布任何第三方辭庫。
