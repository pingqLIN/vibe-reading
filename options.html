網頁翻譯相關設定（變更即時生效，無需重新整理）

在網頁上按住此鍵並將滑鼠移到段落上，即翻譯游標所指的那一段。
常駐右下角的翻譯球。關閉後仍可用工具列圖示／Alt+T／右鍵選單翻譯。

專業辭庫（選用）

固定專業術語譯法；相容 Immersive Translate terms 的 source,target,tgt_lng CSV 格式。
此功能預設關閉。辭庫資料由你自行載入或指定；Vibe Reading 不內建、轉授權或保證任何第三方辭庫。

載入本機 CSV

適合固定版本或自行維護的辭庫；內容會儲存在本機 Chrome storage。

選擇辭庫檔案 檔案上限 2 MB；第一列至少需要 source,target。

直接貼上 CSV

建議包含 tgt_lng；空白或 auto 表示所有目標語言。

遠端辭庫來源

推薦從公開 GitHub 目錄選取辭庫；直接 CSV URL 保留作為進階模式。

支援公開 repository 的 /tree/<branch>/<folder> 目錄。
尚未選擇辭庫
需直接回傳 CSV 文字。遠端只允許 HTTPS；本機開發可使用 localhost 或 127.0.0.1。
變更目錄、勾選項目或直接 CSV URL 後，此確認會自動失效。
只更新已選取項目，最多每 24 小時一次；失敗時沿用上次成功快取。
格式相容與第三方責任

可使用 Immersive Translate terms 相容 CSV。Vibe Reading 僅提供格式與目錄讀取相容，不預載、選取、重新散布或轉授權第三方資料。
